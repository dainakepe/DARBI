# Noteikumi darbam ar šo repozitoriju

## Struktūra

- Viss prototips atrodas vienā failā – `index.html`. HTML, CSS un JavaScript raksta tajā pašā failā.
- Neveido atsevišķus CSS, JS vai datu failus.
- Lapai jādarbojas, atverot `index.html` tieši pārlūkā, bez servera, būvēšanas rīkiem un instalēšanas.

## Dati

- Izmanto tikai izdomātus testa datus.
- Neizmanto īstus personu vārdus, personas kodus, adreses, tālruņa numurus, e-pastus vai citus reālus datus.

## Valoda

- Visa saskarne (teksti, pogas, paziņojumi) ir latviešu valodā.
- Dokumentācija (`README.md`, `CLAUDE.md`, komentāri kodā) ir latviešu valodā.

## Pēc izmaiņām

- Pēc katrām izmaiņām `index.html` atjaunini `README.md`, lai tas atbilstu prototipa pašreizējam stāvoklim (piemēram, sadaļa „Pašreizējais stāvoklis”).
